# 按本次模式填写的工作卡

空字段供填写，不要求完成无关题型。说明不进入学生卷面。

## A. 任务卡：先锁定本次成品

|字段|填写内容|
|---|---|
|目标卷种与模式|英语一/二；Cloze、阅读A、B具体类型、翻译英语一/二|
|本次数量|几篇、每篇完整任务；不是只展示一个空|
|已知偏好|主题、热点辅助、当前篇幅和版式；已有会话信息直接沿用|
|已用文章|查重范围、已用来源ID、是否与真题或旧训练相同|
|已有材料|真题库、原文、用户粘贴、已核版本和缺失范围|
|输出|完整PDF、可编辑底稿、必要出处；是否另需其他格式|
|试题与答案版式|英语一已认可版／英语二2024版；独立试题＋按篇英中对照答案册|
|整卷蓝图|各卷7个单元、topic及题型分工、跨卷查重、分值和题号|
|验收层级|自查、独立审题或试测实际能做到哪一层|
|当前例外|篇幅、段数或结构例外及理由；没有就写无|

已经明确的参数不反复询问。确定本次范围后执行，除非缺失信息确实阻塞选材或交付。

## C. 未命题正文与删改卡

先写一个简短主线概括，再做删改：

```text
原文单元范围（整篇 / 章节 / 起止句）：
该单元要保的主张、证据和限定：
拟保留的学生正文主线：
原文全文词数（未核则留空，不用片段冒充）：
有界单元词数 / 学生正文词数 / 计数口径：
```

|操作ID|原文位置与版本|保留/删除/替换/合段/重排|理由|受影响关系及题位|删后如何核验|
|---|---|---|---|---|---|
|逐项填写|页段/句或可回查坐标|具体操作，必要时留原词与新词|主线和任务需要|指代、条件、否定、因果、比较、主张归属等|恢复上下文/语义对照/换段等|

删后检查：哪些必要证据还在？是否改变适用人群、原因主次或作者态度？能否只凭学生正文完成任务？需要在解析里偷偷补被删背景的，先修正文或任务。

本卡不规定删改比例；净词差不等于实际删除量或原意损失。

## D. 选择题工作卡：阅读A每题、完形每空

```text

必须保留的主体、条件、范围、程度或逻辑：
```

|选项|在文中的真成分或局部可通之处|具体冲突/无据/任务不合之处|证据|仍有竞争吗|
|---|---|---|---|---|
|A|即使是错误项也公平找支持|不只写“偷换概念”|卷面可见文本|是/否及原因|
|B|同上|同上|同上|同上|
|C|同上|同上|同上|同上|
|D|同上|同上|同上|同上|

再单独写：最强竞争是哪项？替它辩护的最有力文内依据是什么？当前题干如何排除？若排不掉，修改题干/空位/选项、恢复原句或换题，不能只说参考答案如此。

阅读A：五题分工是什么？是否重复证据、跨题泄题？NOT/EXCEPT是否按负向任务解释？

完形：全部20空都留空时，本空线索还在吗？是否依赖另一指定答案？四项逐一回填后分别属于句法、搭配、动作、语义角色、程度或逻辑哪种问题？语法可通不写语法错误。

## E. 完形整套卡

```text
回填正文 / 印出正文 / 20空及80项：
每空正确答案回填后是否与底稿一致：
首空前、末空后保留信息：
相邻空之间印出词数数组：
最拥挤的局部及调整理由：
同短语连续挖词、循环依赖、多解词检查：
回填全文、答案、译文、解释是否同版本：
```

平均空距不代替局部判断。参考约300词，不能为了多20词自写一句补进去；需要增补时从真实原文恢复合适内容。

## F. Part B整组卡

先填：题型、正文版本、五个作答位置、候选数、是否允许复用、固定位置、是否有不用项/不用段。默认规则不能代替实际题干。

### 匹配 / 小标题

做五对象或五节×七项表，每格写“支持 / 不支持 / 有条件或局部支持 + 具体依据”。35格不是35个新题。

人物匹配另保存“谁—主张—理由—条件”；标题先保存每节独立概括。说明两项为什么全套不用，而不是宣称它们在外部事实层面必假。局部也支持的对应如实记录，不只靠某项已被分配来掩盖歧义。

### 补句 / 语段还原

|空位|空前约束|空后约束|正确项原文位置|最强可互换项及断裂|修改|
|---|---|---|---|---|---|
|41—45各一行|指代/引入/逻辑等|回应/例证/比较等|正确项有真实依据|同主题不等于衔接|需要则改|

分别统计留空正文、五个正确语段、回填全文、七候选与全部阅读负荷。交换候选并整篇重读；不要用外部常识识破编造事实来代替文内判断。

### 排序

```text
所有真实段落及原文定位：
固定位置和给定段：
参考完整顺序：
关键衔接边及依据（引入、回指、时序、问答、总分等）：
最强完整竞争顺序1及具体断裂：
最强完整竞争顺序2及具体断裂：
是否仍有同样自然的顺序？怎样修订：
```

枚举只检查人工约束是否自洽，不证明自然语言唯一。无约束可自由交换的段落应改作固定位置、换选段或换文。

## G. 翻译卡：按卷种选用

### 英语一

|题号|精确原文起止/段号/词数|主要任务|未画线上下文作用|参考译文与可接受变体|模拟误译及错因|
|---|---|---|---|---|---|
|46—50各一行|不能靠下一题号猜终点|一项主要任务即可|指代/前提/词义/比较|关系准确，中文可多样|明确是模拟|

整套再核五处分布、重复任务及总负担；全文约420—440词、五处约153—160词作为软目标。全文译文提供语境，逐题译文只覆盖画线范围。

### 英语二

```text
约155词正文的完整叙述/解释线：
按实际句界分句及必要意义单元：
每句主干、关键搭配、修饰和语气：
人物/术语/代词/时序统一表：
全文连续译文：
可接受替代或拆合句及成立条件：
模拟误译、具体错接关系：
全篇回读：结论是否回应开头，有没有局部都顺而主题错位？
```

两卷均核信息、关系、限定、中文自然度，不虚定官方词组采分点。参考译文不等于逐字唯一答案，没有试测不报告得分预测。

## H. 全文与交付放行卡

|检查|通过依据或问题处理|
|---|---|
|真实性|出处、正文及版本可回溯；没有自写正文冒充原刊|
|学生文自足|主线、证据及限制完整，不靠被删材料作答|
|题型完整|数量、编号、全部候选、固定位置与题干一致|
|关系/竞争|正确项或译文保关系；所有竞争项有具体理由，多解已修订|
|整组|无循环依赖、无重复/泄题，匹配/排序/补句全局可成立|
|统计|正文、回填、候选、数字/姓名口径清楚，不拿总阅读负荷冒充原文长度|
|版本|正文、题目、答案、译文、解释同版本，旧版不混用|
|PDF|全部最新页面实际渲染目视；必要的提取/回填与底稿核对已做|
|交付|整卷试题与答案分文件；答案按篇英中对照、解析、出处连续编排，无独立全文译文附录；ZIP为最新版|
|结论边界|自查不称盲审；无词表/试测/官方评分依据不报相应指标|

放行状态：完成 / 已交付待反馈 / 需修订 / 缺信息。缺口说具体，不笼统写“已通过全部验证”。用户认可、同作者自查、独立审题和学生试测分别记。

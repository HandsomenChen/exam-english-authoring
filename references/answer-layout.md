# 考研英语答案册：按篇整合模板与紧凑排版规范

项目默认版式，可按用户新要求配置；下文历史批次数字仅作对照。

## 1. 核心原则

**同一篇文章的英文、中文译文、答案解析和出处放在同一连续单元中。** 不再先排所有答案，后面另加整本译文。答案册允许自然跨页，但不能为了单篇独占整页不断产生大块空白。

保留完整选文和完整必要解释，压缩重复与空白，不压缩信息。当前四卷28个单元、152组英中段落由95页整合为48页，属于本批实例；未来按内容自然排页，不固定48页或固定压缩比例。

## 2. 全册顺序

```text
简短总标题与必要使用说明（与第一卷同页，不独占封面）

英语一 A卷
  答案速查
  完形：英中对照 → 20空解析 → 出处/删改
  阅读Text 1：英中对照 → 21—25解析 → 出处/删改
  阅读Text 2、3、4：同上
  新题型：还原后的英中对照 → 完整答案与衔接/匹配依据 → 出处/删改
  翻译：全文英中对照 → 46—50参考与处理要点 → 出处/删改

英语一 B卷：同结构
英语二 A卷：同结构；翻译为46全文，参考译文与右栏合一
英语二 B卷：同结构
```

卷间用分隔线、卷名和PDF书签区分。有足够空间可以同页进入下一卷，不强制另起页；内容不足以放标题、速查与开篇时再换页。

答案速查仅列客观题字母，可按1—5、6—10等五题一组；41—45单列。逐题解析仍放对应篇下，速查不是解析替代品。翻译参考不塞进字母表。

## 3. 每篇可复用模板

```text
模块名：完形填空 / 阅读Text n / 新题型 / 翻译
原刊篇名（仅答案册显示）

┌ 英文原文（卷中删节稿） ┬ 中文对照 ┐
│ [段落标识] 本段英文      │ 同段中文 │
│ [下一段标识] ……          │ ……       │
└──────────────────────────┘

答案与解析
题号. 正确字母＋答案词或正确项
证据与解题关系；具体干扰机制；必要时点明最强竞争为何不成立。
……本篇所有题目……

出处：出版物／机构、作者、日期
可点击原文URL
许可与使用依据、必要的许可URL
删改说明：保留什么、删去什么、有限措辞修复及仍未确认的信息
```

“英文原文”必须明确是卷中采用的删节稿，不是外刊未删节全文。未核实的发稿日不能用活动日期或抓取日代替。来源性质、发言归属和授权说明如实填写，不暗示原机构为题目背书。

## 4. 不同题型怎样还原及写解析

### 4.1 完形

- 英文列用20个正确答案回填后的完整正文，中文按同一稿逐段翻译。
- 逐空列题号、字母、答案词或词组；说明语义、搭配、句法或逻辑约束。
- 具体解释其他选项为什么不合，尤其是最强竞争；允许合并表述，但不只写“原文如此”。
- 英文原词不能证明唯一。四项比较详表保留内部，公开解析要足以复盘。

### 4.2 阅读A

- 正文与译文逐段对齐；后面紧接本篇五题。
- 每题列正确字母及正确项，再写卷文证据、必要推理和三项干扰的具体错误关系。
- 不默认重印整套题干、四个选项及其中文，避免把试题再复制一次；遇到辨析需要可补短引文或选项译意。
- 不能在解析里补入被删原文作为答案依据，缺证据应回到正文或题目修订。

### 4.3 新题型

|形式|英中对照展示|答案解析内容|
|---|---|---|
|排序|恢复正确全序，保留卷面原段落字母|41—45字母、全序、关键相邻关系与最强竞争断裂；给定段也在全序中|
|补句|将五个正确句/段放回原位置，保留必要空号定位|五空答案、空前与空后依据、两个多余项不能放入的原因|
|标题|保留五节及编号，正确小标题可在解析列出|五个对应、每节主旨、相近标题的范围差别、两项多余原因|
|人物信息匹配|保留真实人物名及相关发言顺序|五对答案、人物—观点/理由证据、两项多余及易混对象区别|

不用项若是题外人物真实观点，不能说成外部事实错误；“全套不用”和“内容为假”分开。不要只给五个字母、缺少整组关系说明。

### 4.4 英语一翻译

- 左栏给完整卷文，保留46—50的精确题号与下划线；右栏补齐全文中文，包括非画线部分。
- 后面逐题给画线范围的参考译文与处理要点；全文语境和目标句答案的用途不同，可保留这项必要的局部重复。
- 处理要点聚焦主干、指代、修饰、否定、情态、搭配与自然中文，可记合理替代；不把一种中文表述当唯一答案。
- 不重复再附一份相同的英语全文，不自行声称某词必得0.5分等官方细项。

### 4.5 英语二翻译

- 左栏短文、右栏逐段连续译文就是46题全文参考。
- 后面给关键搭配、句法与篇章衔接处理要点；必要时补可接受替代和模拟误译。
- 不把同一篇完整中文在右栏和下方各排一次；分段呈现仍需保证连起来是一篇自然完整的中文。

## 6. 自然续页与减空白规则

1. 简短说明放首卷上方，不另设空旷封面。
2. 不强制每篇另起一页。标题下还能容纳约130pt内容时，可以接着排；不足则换页。
3. 卷间有约180pt可用空间时可进入新卷；用清楚分隔线即可，不为卷界留下半页以上空白。
4. 中英文按段号相配，长段允许跨页；每页续表重复列头。分割后的两列仍属于同一原段，不虚造新段号。
5. 不为强行整段同页留下半页空白。极短续行、仅一列有少量续文等情况要目视判断，必要时小调分页。
6. 避免把模块标题、篇名和整篇大表绑定为不可拆的一块，否则即使当前页有空间也会整体被推到下一页。
7. 模块标题至少与篇名同页；“答案与解析”与第一条解释相连；每题题号与解释不要拆开。
8. 出处可以自然接排，必要时续页，但不故意另起一张只放URL和许可。
9. 优先删除重复全文译文、重复说明、无必要大间距和硬分页，保留必要证据与译文。
10. 内部审查每页正文占用和最下行位置，找明显空页及稀疏页；不用统一“填满率”强迫自然结束页塞内容。

试题卷和答案册的分页目标不同，不能把这里的紧凑分栏套给正式作答试卷。

## 7. 内容与版面双重验收

- [ ] 全部卷、全部7个单元与题号都有，不漏最后一篇翻译。
- [ ] 英文逐字对应卷中删节底稿；完形/排序/补句还原正确。
- [ ] 英中段落数量、标识和含义对应，无缺段、重复、串位或漏译限制条件。
- [ ] 每题答案字母、正确项文本、速查表、解析一致；改过选项顺序的全部同步。
- [ ] 翻译画线范围正确；英语二全文译文只完整呈现一次。
- [ ] 来源与删改说明归属本篇，没有把别篇URL或作者带入。
- [ ] 每个标题和题号有后续内容，无整篇被不必要地推页。
- [ ] 中文、引号、连字符、人名和表头无缺字、黑方块或裁切。
- [ ] 续表表头、段号、页眉页脚、页码与PDF书签可用。
- [ ] 最终全部页面渲染目视通过；文本提取检查只是补充，不替代看图。
- [ ] 仅改答案排版时，配套试题PDF保持不变；完整包内答案为同一最新版。

保存实际检查页数、正文与译文单元数、修订范围、未解决问题及版本哈希。没有进行的独立审题和试测不填“通过”。
